# હડાદ પોલીસ સ્ટેશન – નોકરી પત્રક અને બંદોબસ્ત વ્યવસ્થાપન

## GitHub પર મૂકવાના સ્ટેપ
1. github.com પર નવી રિપોઝિટરી બનાવો (દા.ત. `hadad-police-app`).
2. આ ઝીપની બધી ફાઇલો (`index.html`, `README.md`, `.github` ફોલ્ડર) `main` બ્રાન્ચમાં અપલોડ કરો.
3. Settings → Pages → Source: **GitHub Actions** પસંદ કરો.
4. લિંક: `https://<યુઝરનેમ>.github.io/hadad-police-app/`

## એડમિન (ફેરફારનો અધિકાર)
- ઉપર જમણે **એડમિન લોગિન** → PIN: `1234` (લોગિન પછી **PIN બદલો** થી બદલી નાખજો).
- એડમિનને જ નવો સ્ટાફ ઉમેરવો, સ્ટાફ/નોકરી/ગ્રુપ/સ્થિતિ બદલવી, કમી કરવો, પત્રક બનાવવું-બદલવું દેખાય છે. બીજા લોકો ફક્ત જોઈ/પ્રિન્ટ કરી શકે.
- નોંધ: આ PIN ફક્ત દેખાવ પૂરતું રક્ષણ છે, સાચી સિક્યોરિટી નથી.

## બધાને નવો ડેટા કેવી રીતે દેખાય?
1. એડમિન તરીકે ફેરફાર કરો (ડેટા તમારા બ્રાઉઝરમાં સેવ થાય છે).
2. ડાબી બાજુ **data.json ડાઉનલોડ** દબાવો.
3. GitHub રિપોઝિટરીમાં એ `data.json` અપલોડ કરો (જૂની બદલો).
4. હવે બધા માટે પેજ ખોલતાં નવો ડેટા દેખાશે.
